## 📖 Sobre o projeto

Este repositório foi criado para armazenar estudos, práticas e projetos desenvolvidos utilizando **Node.js**.

O objetivo é aprender os conceitos fundamentais do ambiente Node.js, incluindo:

- Estrutura de projetos
- Módulos
- NPM
- Manipulação de arquivos
- Servidores HTTP
- APIs
- Programação assíncrona
- Express.js (quando aplicado)

## ⚙️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/rufinoannabeatriz9-cyber/ambiente-nodejs.git
```

### 2. Entre na pasta

```bash
cd ambiente-nodejs
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
node index.js
```

Caso utilize **Nodemon**:

```bash
npm run dev
```
